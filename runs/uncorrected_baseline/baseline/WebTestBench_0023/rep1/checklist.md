# Test Checklist

## Functionality
- [ ] FT-1: Sellers can create product listings that include photos, descriptions, prices, and locations.

- [ ] FT-2: Sellers can update the details of existing product information.

- [ ] FT-3: Sellers can update the information of the products they own.

- [ ] FT-4: The shopping cart cannot contain items that have been removed or are no longer available.

- [ ] FT-5: Users can register new accounts

- [ ] FT-6: Buyers can filter and sort products by category, price range, condition, and distance.

- [ ] FT-7: Buyers can search for products using keywords.

- [ ] FT-8: Buyers can add items to their shopping cart

- [ ] FT-9: Buyers can send shopping requests

## Constraint
- [ ] CS-10: Users cannot log in if they do not have a registered account.

- [ ] CS-11: Accounts that have already been registered cannot be registered again.

- [ ] CS-12: Unable to log in when user account password is incorrect.

- [ ] CS-13: Sellers cannot update other people's product information.

- [ ] CS-14: Users need to fill in the necessary fields to create product information.

- [ ] CS-15: Prices must be non-negative numbers.

## Interaction
- [ ] IX-16: Creating duplicate accounts provides visual feedback.

- [ ] IX-17: Search results are displayed in real time when users use the search function.

- [ ] IX-18: The filtering results are displayed in real time when the user uses the filtering function.

- [ ] IX-19: Provide visual feedback when users add items to their cart.

## Content
- [ ] CT-20: All product photos displayed must be related to the used or upgraded products described in the product details.
