# Test Checklist

## Functionality
- [ ] FT-1: Users can create financial records by writing text input fields.

- [ ] FT-2: Users can view the financial dashboard.

- [ ] FT-3: Users can search for financial information by entering keywords.

- [ ] FT-4: Users can view and print basic financial summary tables.

- [ ] FT-5: Users can filter the product list by product category (such as expenditure, date, transaction).

- [ ] FT-6: Users can create new financial records.

- [ ] FT-7: Users can manage the financial records they have created.

- [ ] FT-8: Users can customize account categories or accounts.

- [ ] FT-9: Users can categorize the financial records they create.

- [ ] FT-10: Users can view and adjust various items.

- [ ] FT-11: Users can mark projects as tax-related.

## Constraint
- [ ] CS-12: After a user applies filtering or sorting criteria, the product results displayed by the system must strictly match the selected criteria.

- [ ] CS-13: Users cannot create financial records without any input.

- [ ] CS-14: When adding a new financial record, the selected time period cannot be a future time.

- [ ] CS-15: The start time of the filtering dates must be earlier than the end time.

## Interaction
- [ ] IX-16: Dashboard information changes in real time when financial information is added, edited, or deleted.

- [ ] IX-17: When a user marks a project as tax-related, the corresponding page should provide feedback.

- [ ] IX-18: When users create and manage financial records, custom accounts show the already assigned records.

- [ ] IX-19: Click "Print Report," and the printed report will appear in the document selection menu.

## Content
- [ ] CT-20: Users can view their spending and expenditure details.

- [ ] CT-21: The information on the financial dashboard must match the actual financial information entered.
