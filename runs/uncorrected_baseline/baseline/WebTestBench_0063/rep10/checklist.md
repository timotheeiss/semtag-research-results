# Test Checklist

## Functionality
- [ ] FT-1: Users can view a list of all intangible cultural heritage items on the website.

- [ ] FT-2: Users can click on a heritage item from the list to navigate to its dedicated details page.

- [ ] FT-3: Users can view complete details of heritage projects on their details page, including titles, descriptions, images, and regional information.

- [ ] FT-4: Users can browse cultural heritage projects organized by type and category (traditional crafts, folk customs, performing arts).

- [ ] FT-5: The state is not lost after all operations on the page.

- [ ] FT-6: The page should provide corresponding prompts for issues such as slow panorama loading and inability to open product detail page images.

## Constraint
- [ ] CS-7: Each heritage item must belong to at least one valid category (traditional crafts, folk customs, or performing arts).

- [ ] CS-8: You will be directed to the heritage project details page only when you click on a valid heritage project.

- [ ] CS-9: Each heritage item on display must include all required fields (title, description, region).

## Interaction
- [ ] IX-10: The navigation between the list view and the details view maintains a clear visual distinction between the two interface states.

## Content
- [ ] CT-11: All exhibited artifacts must be genuine Chinese intangible cultural heritage items, and all are based on authentic and reliable historical materials and knowledge.
